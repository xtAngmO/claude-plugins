# claude-plugins

Claude Code plugins by [xtAngmO](https://github.com/xtAngmO).

```
/plugin marketplace add xtAngmO/claude-plugins
```

| Plugin | What it does |
| --- | --- |
| [tsserverd](plugins/tsserverd) | TypeScript/JavaScript LSP that shares one tsserver per project root across all Claude Code sessions, instead of starting a 2–4 GB tsserver in every session. Works on Windows. |

Install a plugin with `/plugin install <name>@xtangmo`.
